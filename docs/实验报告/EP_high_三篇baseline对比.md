# EP_high：三篇论文方法 vs 我方方法（独立对比工程）

> 2026-09-12 | 工程：baseline_ep_high/（独立自包含，不依赖被改过的 main.py）
> 数据：EP_high.off，1,392,236 顶点 / 8,337,166 条边 —— 我们的 terrain 主数据集

---

## 一、协议（与主实验完全对齐）

| 项目 | 取值 |
|---|---|
| 真值标签 | flip-out 精确表面测地距离，50,000 对（与主实验同一份 CSV） |
| 切分 | 80/10/10，random.seed(42)，按 CSV 行序（等价 preprocess.split_distance_dataset） |
| test 集 | 5,000 对 |
| 指标 | MRE = mean(abs(pred-true)/true)、MAE、RMSE |
| 参照 | 同一 test 集上的 3D 直线距离（纯欧氏，无学习） |
| 训练预算 | 六个配置统一 100 轮、batch 8192、Adam lr=1e-3 + ReduceLROnPlateau(0.5, patience 8) |

三篇实现与适配（论文表格需标注）：
- **GeGnn**：GeoConv（max 聚合 + 边长/相对位置消息）+ GroupNorm(4)；保持官方宽度 256 / 4 层。
  为在 24GB 卡上处理 8.34M 条边，消息按目的节点分块 + 块级梯度检查点（数学等价，仅省显存）；省略 hgraph 层级池化。
- **NeuroGF**：逐点 lifting + GDF 差分头，与官方实现一致（不使用图结构）。
- **LiteGE**：CoordMLP（BN-MLP）同构；UDF-PCA 描述子适配为「按 (x,y) 切 patch 当形状集」。

## 二、结果（100 轮）

| 方法 | 输出参数化 | test MRE | MAE | RMSE | 相对纯欧氏 |
|---|---|---|---|---|---|
| **纯 3D 欧氏直线（无学习）** | — | 0.19306 | 1590.73 | — | 1.00x |
| **我方方法（三段式 + 欧氏残差）** | 欧氏残差 | **0.03220** | **199.40** | **499.76** | **6.00x** |
| LiteGE | 欧氏残差 | 0.07641 | 525.71 | 802.40 | 2.53x |
| GeGnn | 欧氏残差 | 0.08255 | 552.51 | 844.76 | 2.34x |
| NeuroGF | 欧氏残差 | 0.19336 | 1493.21 | 1935.34 | 1.00x |
| NeuroGF | 原样 | 0.51621 | 3546.90 | 4608.96 | 0.37x |
| GeGnn | 原样 | 0.63553 | 4673.58 | 5771.86 | 0.30x |
| LiteGE | 原样 | 0.97358 | 7755.41 | 8611.28 | 0.20x |

各配置最佳轮次：GeGnn+ER 45、GeGnn 原样 61、LiteGE+ER 72、LiteGE 原样 6、NeuroGF+ER 69、NeuroGF 原样 29。

## 三、结论

1. **在 EP_high 上我方方法全面领先**：0.03220，比最好的 baseline（LiteGE+欧氏残差 0.07641）好 **2.37 倍**，
   比 GeGnn+欧氏残差（0.08255）好 2.56 倍，比纯欧氏直线好 6.00 倍。
2. **三篇的原生输出全部失效**（0.52 ~ 0.97，均差于"量直线"）：再次印证「输出参数化（有没有欧氏锚点）
   比网络结构更关键」这一跨规模结论。
3. **方法优劣随规模反转**：在 small / BH / EP_low 上 NeuroGF+欧氏残差最好（0.13% / 0.83% / 0.59%），
   但在 EP_high（139 万顶点 / 834 万边）上它退化到 0.1934（与纯欧氏持平）——因为其实现不含图上的消息传递，
   只有逐点特征 lifting，规模一大就无法表达全局测地结构；而 GeGnn（有图卷积）仍保持 0.0826。
4. 这正好说明我方「分区 + 高速公路图 + 三段式 GNN」的可扩展性设计在**主数据集规模**上才体现出决定性优势。

## 四、公平性说明（写作时需写进实验设置）

- 六个配置共用同一份真值、同一切分、同一测试集、同一轮数与学习率调度。
- 我方方法的数字（0.03220）来自主实验的 100 轮最优配置（surf_res1_h64_k3_100ep）；
  其架构与三篇不同（三段式 + 高速公路图），这正是要比较的对象。
- GeGnn 省略 hgraph 层级池化、LiteGE 的 UDF-PCA 做了单场景 patch 化适配、NeuroGF 忠实于其官方实现（无图消息传递），
  三者都在本工程 README 中记录。
- 所有结果 JSON（含逐轮 val 曲线）在 baseline_ep_high/results/ 下可复核。
