# EP_high 解剖式消融实验（Ablation Study）

> 2026-09-12 | 数据：EP_high.off（1,392,236 顶点 / 8,337,166 条边）
> 真值：flip-out 精确表面测地距离，50,000 对；80/10/10 切分 seed=42（test 5,000 对）
> 指标：MRE = mean(abs(pred-true)/true)，同一测试集，全部 100 轮

---

## 一、总体效果（M0）

| 指标 | 值 |
|---|---|
| test MRE | **0.03294**（残差 ±0.5）／ **0.03220**（残差放宽到 ±1.0） |
| MAE | 205.11 ／ 199.40 |
| RMSE | 548.00 ／ 499.76 |
| 对比纯欧氏直线 | 好 **5.9 倍** |

---

## 二、四个解剖实验

| 配置 | 保留 | 去掉 | test MRE | MAE | 相对 M0 |
|---|---|---|---|---|---|
| **M0 总体方法** | 分区+highway+三段式 GNN+欧氏残差 | — | **0.03294** | 205.11 | 1.00x |
| **A1 去欧氏残差** | 分区+highway+三段式 GNN | 欧氏残差 | **0.04403** | 待补 | 1.34x |
| **A2 去分区+highway** | 单 GNN + 欧氏残差 | 分区、highway | **0.04177** | 254.15 | 1.27x |
| **A3 两者都去** | 单 GNN | 分区、highway、欧氏残差 | **0.69089** | 4221.34 | 21.0x |
| **A4 纯欧氏直线** | 无学习 | 全部 | **0.19306** | 1590.73 | 5.9x |

---

## 三、逐项结论

1. **欧氏残差（Euclidean residual）是最关键的技术**：
   - 保留分区+highway 时去掉它（A1）：3.29% → **4.40%**（劣化 1.34 倍）——结构能部分兜住；
   - 去掉分区+highway 时再去掉它（A3）：4.18% → **69.09%**（劣化 16.5 倍）——直接崩盘，
     甚至比"直接量直线"（19.31%）还差 3.6 倍。
   - 两者合起来说明：**欧氏残差是"能不能工作"的前提，地形分区+highway 是"能用多准"的增益**。
2. **地形分区 + highway 网络贡献明确且稳定**：
   去掉它们、只留一个整图 GNN（A2），MRE 从 3.29% 变为 **4.18%**（劣化 27%），
   仍远好于三篇 baseline（最好的 LiteGE 7.64%）；在无残差条件下它们的价值更大（4.40% vs 69.09%）。
3. **纯欧氏直线**的误差是 **19.31%**（MAE 1590.73），是"完全没有学习"的参照线；
   任何低于它的方法才算真的学到了东西。
4. 值得写进论文的一点：**A2 的 RMSE（543.79）与 M0（548.00）几乎相同，但 MRE 差 27%**
   —— 说明分区+highway 主要改善的是**大多数点对**的相对误差，而不是被少数长距离大误差主导的平方误差。

## 四、实验设置（写作时用）

- 四个配置共用同一份标签、同一切分、同一测试集、同样 100 轮；
- 训练超参一致：Adam lr=1e-3、weight_decay=5e-4、ReduceLROnPlateau(0.5, patience 5)、huber 损失；
- M0/A1 走主实验的三段式管线（sample 缓存 + 分区/highway 上下文）；
  A2/A3 用同口径节点特征（label/degree/x/y 平铺到 64 维，与主方法一致）与同一 GNN 块（GraphSAGE），
  融合头输入维度也与三段式对齐（4×out_dim [+ 欧氏先验]），不靠"砍容量"制造差距；
- A4 在同一测试集上直接算 3D 直线距离。

## 五、2x2 因子设计（交互作用）

|  | 有欧氏残差输出 | 无欧氏残差输出 |
|---|---|---|
| **有地形分区 + highway** | **M0 = 3.29%** | A1 = 4.40%（1.34x） |
| **无分区（单 GNN）** | A2 = 4.18%（1.27x） | A3 = 69.09%（20.97x） |

- 单独去掉任一项：只劣化 27%~34%（两项作用相当）；
- **同时去掉两项：劣化 21 倍**，远大于两项单独劣化之和（1.34 × 1.27 = 1.70 倍）。
  → 两个技术之间存在强**交互作用**：欧氏残差负责把预测锚定在物理量纲上，
    地形分区+highway 负责在锚定范围内提升精度；缺了锚点，再好的结构也救不回来。
