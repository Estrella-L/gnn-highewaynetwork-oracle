## 四、跑完后怎么填矩阵

每次训练产物：`outputs/results/<图>_<tag>.txt`，取 `test_relative_error` 行 ×100 即 MRE%。
批量抽取：

```powershell
Get-ChildItem outputs\results\*_s42_100ep.txt | ForEach-Object {
  $kv = @{}; Get-Content $_ | ForEach-Object { $p = $_ -split '\s+',2; if ($p.Count -eq 2) { $kv[$p[0]] = $p[1] } }
  "{0},{1},{2},{3}" -f $_.BaseName, $kv['architecture'], $kv['prediction_mode'], ([double]$kv['test_relative_error']*100)
}
```

> 注意：`single_gnn` / baseline 分支的 `architecture` 行会写明方法名，按 run_tag 对号填表。
